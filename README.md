One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement. This entry is for the
[Absurd Clause Contest](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1)
on make.fun.

## Entry

> The User shall mow the Company's lawn every third Sunday, in a suit, and wave at the neighbours as if this had always been the arrangement.

## How it works

`main.py` writes the clause above to `/output/entry.txt`. Nothing else.
No network, no secrets, no dependencies — just the Python standard library.
